# ESPAÑA ATLAS v4 — AI相談・詳細情報・空港

## 使い方
ZIPを展開し、index.html、style.css、script.jsを同じ階層に置いて開いてください。GitHub Pagesには3ファイルを公開リポジトリのルートにアップロードします。

## 追加機能
- スポットをクリックすると、詳細情報、入場区分、料金の確認方法、確認済み施設の公式リンクを表示します。
- クラブをクリックすると観戦料金は変動と明示し、LaLiga公式日程およびスタジアム検索へ案内します。販売サイトの推測リンクは作りません。
- 交通タブで主要空港16か所を青色の✈マーカーで表示。空港ピンをクリックするとAenaの公式情報が開けます。
- ユーザー自身のChatGPTで相談するリンクと、質問文コピー機能を追加しました。サイトにAPIキーは不要ですが回答が地図に自動反映されるわけではありません。

## 重要な注意
- 料金は変動します。正確な価格を取得していない施設は「未確認」と表示し、仮の数値は載せません。
- クラブロゴ、写真、自治州境界などは通信が必要な場合があります。
- AI検索はサイト内実行ではなく、自分のChatGPTで相談する方式です。
- 主要空港はAena公式一覧から抜粋。全空港ではありません。
- 駅・鉄道や一部クラブ・観光地のデータは旧v3の参考情報を引き継いでいます。
